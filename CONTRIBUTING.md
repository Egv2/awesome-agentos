# Contributing to Awesome AgentOS

Thank you for your interest in contributing! This list curates the best open-source tools, frameworks, and platforms for building agent operating systems — the full stack that gives AI agents their capabilities.

## What Belongs Here

An entry belongs on this list if it helps **build, run, or extend an agent operating system**. This includes:

- **Agent frameworks and orchestrators** — multi-agent coordination, state management, durable execution
- **Computer-use and desktop automation** — agents that control operating systems and applications
- **Web agents and browser automation** — agents that browse, scrape, and interact with the web
- **Voice and conversational AI** — TTS, STT, voice assistants, real-time audio for agent pipelines
- **Visual and creative AI** — image, video, and 3D generation that agents can leverage
- **Developer tools and code assistants** — coding agents, IDEs, and development environments
- **LLM infrastructure** — model serving, fine-tuning, API gateways, inference optimization
- **Security tools** — penetration testing, red teaming, vulnerability scanning powered by agents
- **Data, memory, and knowledge** — OCR, knowledge graphs, memory systems, document processing
- **Datasets and benchmarks** — open datasets, evaluation suites, and reference collections
- **Productivity and personal assistants** — chat interfaces, AI companions, and workspace tools
- **MCP and tool integration** — Model Context Protocol servers and tool connectivity

## Submission Guidelines

Before submitting a pull request, ensure your contribution meets these criteria:

- **Open source.** The project must be publicly available under an open-source license.
- **Actively maintained.** Archived, deprecated, or unmaintained projects are not accepted.
- **Relevant.** The project must contribute to the agent OS ecosystem (see above).
- **Well-described.** Provide a clear, objective description of what the project does.

## Formatting

Follow this exact format for each entry:

```
- [Project Name](https://github.com/author/project) - Description starting with an uppercase letter and ending with a period.
```

### Description Rules

- Start with an uppercase letter.
- End with a period.
- Describe what the project **does**, not what it **is** (e.g., "Translates documents using AI" not "An AI translation tool").
- Avoid superlatives like "best", "leading", "state-of-the-art" unless part of the official project name.
- Do not include the project name in the description.
- Keep descriptions to one sentence.

## How to Submit

1. **Fork** this repository.
2. **Add** your project to the most appropriate category.
3. **Verify** the formatting matches existing entries.
4. **Submit** a pull request with a clear title (e.g., "Add Project Name").

Thank you for helping make this list awesome!
